# 收尾

## 1. 先跑 `/simplify`(别等他点)

扫本窗口的改动做复用 / 简化 / 效率 / altitude 收口。注意:simplify 别把代码改长,监控文件行数净增会撞棘轮闸。

## 2. 补验证欠账

收尾前把攒下的小批次一起兜:机械闸全套跑一遍、未 push 的 commit 处理掉、CI 是不是真绿(见 `verification` skill)。

```bash
git log --oneline origin/master..master     # 有没有本地没推的
git status                                  # 有没有该提交没提交的
```

## 3. **重写**(不是追加)STATE 顶部状态卡

`CLAUDE.md/STATE_PEARNLY.md` 分割线以上,保持 ≤30 行,永远最新:

- 当前 task
- 最后 commit
- 未 push 的 commit
- 剩余风险
- 下一步
- 在等 Zihao 什么

历史明细往分割线以下追加,不要顶上去。

## 4. 交付报告

**拿 Zihao 的原话当尺子**,逐条对齐他要的东西:

- 做完的:一句话说清"他能看到什么变了"
- 没做完 / 跳过 / 还红的:直说,连原因
- 禁止把缩小后的范围报成"全部完成";禁止用"应该没问题"代替"验过了"
- 大白话,不堆术语,不复述过程

写完就停手,不要顺手开新任务。
