หลักการ系统原则

ค่าคอมนับจากใคร — หลักการของระบบ提成认谁 — 系统原则

  • 1DMS คิดค่าคอมมิชชั่นจาก บัญชีผู้ใช้ที่ล็อกอินสร้างใบจอง และลงชื่อคนนั้นในช่อง «ที่ปรึกษา»DMS 按登录建单的用户账号计提成，并把此人署名到«顾问»栏
  • 2ช่อง «ที่ปรึกษา» ถูกล็อกหลังเปิดใบจอง — เปลี่ยนเป็นคนอื่นภายหลังไม่ได้«顾问»栏建单后即锁定，事后不能改成别人
  • 3Pearnly จึงตรวจสอบและลงชื่อผู้ขายให้ถูกต้อง ก่อนเปิดใบจอง ทุกครั้ง因此 Pearnly 在建单之前就把销售身份核对并署名正确
  • 4ผลลัพธ์: พนักงานขายผู้ทำรายการ = ที่ปรึกษาในใบจอง = ผู้รับค่าคอม — คนเดียวกันเสมอ结果：操作的销售 = 单上的顾问 = 拿提成的人 — 永远同一人
คำเดียวกันสองชื่อ: «พนักงานขาย» กับ «ที่ปรึกษา (ที่ปรึกษาการขาย)» คือตำแหน่งเดียวกัน — ใบจองใช้คำว่า ที่ปรึกษา同一职位两个叫法：「销售」与「顾问（销售顾问）」是同一岗位 — 订车单上叫«顾问»
ขั้นที่ 1 · ตั้งค่าครั้งเดียว第 1 步 · 一次性设置

เพิ่มพนักงานขายในระบบ Pearnly在 Pearnly 里添加销售

  • 1กรอกชื่อที่แสดง + บัญชี DMS ของพนักงานคนนั้นเอง (หนึ่งคน หนึ่งบัญชี)填显示名 + 该销售本人的 DMS 账号（一人一号）
  • 2เลือกบทบาท พนักงานขาย角色选销售
  • 3ช่องค่าคอมมิชชั่น ปล่อยเป็นค่าเริ่มต้น จับคู่อัตโนมัติตามบัญชี DMS提成归属保持默认「自动匹配（按 DMS 账号）」
  • 4ส่ง รหัสผูก LINE ให้พนักงานผูกแชทของตัวเอง发 LINE 绑定码给销售绑定自己的聊天

ขั้นที่ 2 · โหมดอัตโนมัติ (เส้นทางหลัก)第 2 步 · 自动模式（主路）

ใครทำใบจอง ระบบลงชื่อคนนั้น谁建单，系统就署谁

1 พนักงานขายทำใบจองผ่าน LINE ของตัวเอง销售在自己的 LINE 里建订车单 ตอบคำถาม 8 ข้อตามปกติ照常回答 8 个问题
→
2 ระบบเข้าสู่ DMS ด้วยบัญชีของเขาเอง系统用他本人的 DMS 账号登录 ตามที่ตั้งค่าไว้ในขั้นที่ 1按第 1 步的设置
→
3 ตรวจชื่อกับฐานข้อมูลพนักงานใน DMS与 DMS 员工数据库核对身份 ต้องตรงหนึ่งเดียวเท่านั้นจึงผ่าน必须唯一命中才放行
→
✓ ช่อง «ที่ปรึกษา» = ตัวเขาเอง → เปิดใบจอง«顾问»栏 = 他本人 → 建单成功 ค่าคอมลงถูกคน提成落对人
ไม่ต้องเลือก ไม่ต้องพิมพ์ชื่อใคร — ระบบทำให้เองทุกใบ พนักงานแค่ทำใบจองตามปกติ不用选人、不用打任何名字 — 每一单系统自动完成，销售只管正常建单
ขั้นที่ 3 · โหมดปักหมุด (กรณีพิเศษ)第 3 步 · 钉死模式（特殊情况）

กำหนดที่ปรึกษาตายตัวให้บางบัญชี给某些账号固定指定顾问

  • 1ในหน้าตั้งค่า เปลี่ยนช่องค่าคอมมิชชั่นจาก «อัตโนมัติ» เป็นเลือกชื่อที่ปรึกษาจากรายการ在设置页把提成归属从「自动」改成从名单里选定一位顾问
  • 2ทุกใบจองของบัญชีนี้จะลงชื่อที่ปรึกษาคนที่เลือกไว้ เสมอ此账号建的每一单都固定署名所选顾问
  • 3เหมาะกับ: ผู้ช่วย/ธุรการทำใบจองแทนที่ปรึกษา · บัญชีที่จับคู่อัตโนมัติไม่ได้适用：助理/文员替顾问建单 · 自动匹配认不出的账号

ขั้นที่ 4 · ระบบไม่เดา第 4 步 · 系统不猜

กรุณาติดต่อผู้ดูแลระบบเพื่อตั้งค่าพนักงานขาย แล้วทำรายการใหม่อีกครั้ง无法确定此账号对应的顾问，因此暂不建单

  • 1ระบบยังไม่เปิดใบจอง และไม่มีข้อมูลถูกบันทึกแม้แต่รายการเดียว系统不建单，一个字都不写入
  • 2ผู้ดูแลเพิ่มพนักงาน (ขั้นที่ 1) หรือปักหมุดที่ปรึกษา (ขั้นที่ 3)管理员按第 1 步补设置，或按第 3 步钉死顾问
  • 3ตั้งค่าเสร็จ พนักงานทำรายการใหม่ได้ทันที设置完成后销售立即可重新操作
เหตุผล: ช่อง «ที่ปรึกษา» แก้ภายหลังไม่ได้ การหยุดถามจึงปลอดภัยกว่าการเดา — ค่าคอมจึงไม่มีทางลงผิดคน原因：«顾问»栏事后改不了，停下来问比瞎猜安全 — 提成不可能记错人
