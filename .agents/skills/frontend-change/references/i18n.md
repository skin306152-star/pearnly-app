# Pearnly 多语言

- 主站词典是 `static/i18n-data.js` 的 `window.I18N`；POS、AI 等入口使用自己的词典与引用检查，先核对当前入口，不能只改主站词典。
- 常规产品文案覆盖 `th/en/zh/ja`；`adm-*` 超管键仅要求 `zh/th`。其他入口遵循既有语种契约。范围包括提示、空态、占位符、导出文件名/表头、邮件与 LINE 文案。
- HTML 使用 `data-i18n`、`data-i18n-placeholder` 等已有绑定；动态主站模块注册 `window.subscribeI18n`，切换语言后重新渲染。沿用当前入口机制，不另建一套词典。
- 保持占位符、键名和原文件编码。新语言块按 `th/en/zh/ja`，存量 `zh/en/th/ja` 不为排序重排。
- 术语参考：对账 `กระทบยอด`、销项税 `ภาษีขาย`、进项税 `ภาษีซื้อ`。按最长语言检查布局和漏刷新。
- 主词典运行 `python scripts/check_i18n.py --strict --quiet`；按入口运行 GATES 中的 POS/AI/home 引用检查。横向语言齐全不代表引用键存在。
- 运行受影响页面的语言切换验证，检查文案来源、布局和动态刷新；不往测试页面注入一份测试自带词典来证明翻译完整。
