# 协作约定

- 默认用中文，先说结果，再给必要的证据和限制；普通技术选择自行决定。
- 按当前对话理解目标。已授权且必要的工作持续完成；只有关键歧义、必要信息缺失或不可逆操作尚未授权时才询问，并继续不依赖答复的部分。
- 用户当前指示优先于技能和项目文档中的工作流建议。旧任务记录、示例和历史授权不扩展本次任务范围；“查原因”先只读诊断，“讨论方案”先给分析。
- 根据改动影响选择验证，完成项目要求的检查。没有新改动、失败或新证据，不重复已通过的检查；低风险文档修改不运行业务全套测试。
- 分别说明实现、测试、部署、外部业务结果和用户验收；缺少哪一层证据就如实说明。
- 保护其他任务的分支、暂存内容和数据；只提交、清理本次任务拥有的文件和资源。
- 使用当前任务选定的模型与工具。代理分工按用户要求和实际独立工作决定，不在项目规则中强制指定旧模型或外部 worker。
- 项目知识留在各自仓库；技能只在任务匹配时读取。长任务保存必要的目标、决策、证据和下一步，续接当前任务，不以旧状态卡替换用户的新要求。
